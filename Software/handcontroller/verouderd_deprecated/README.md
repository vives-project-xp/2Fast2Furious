## Magic Glove

Verouderde code die een poging doet tot het werken met een python environment in plaats van met Tensorflow.

Werkt slechts gebrekkig na uitwerking. Het is moeilijk om puur wiskundig "ongeveer een cirkel-vorm" te beschrijven/herkennen/verwerken.
Gesture-recognition is ook gelimiteerd.

We werken verder met Tensorflow.
